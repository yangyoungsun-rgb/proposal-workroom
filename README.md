# 제안 작업실 (Proposal Workroom)

proposal-full-pipeline 스킬의 P1~P8 제안 단계를 웹 화면에서 진행하고,
산출물 미리보기 · 검토 의견 · PM 승인 · 잠금을 관리하는 서비스의 **화면 시안**입니다.

## 실행

설치할 것이 없습니다. `index.html`을 브라우저(크롬·엣지)로 열면 됩니다.
판독기 라이브러리(pdf.js, JSZip, mammoth)와 글꼴을 CDN에서 받으므로 인터넷 연결이 필요합니다.

## 지금 되는 것

| 기능 | 상태 |
| --- | --- |
| 공고문·제안요청서 업로드 → 요구사항·작성 지시·감점/실격 조항·사업 개요 추출 | 실제 동작 (브라우저 안에서 처리, 외부 전송 없음) |
| trace.csv · ins.csv 내려받기 | 실제 동작 |
| 진행판(결재란), 승인함, 검증 대시보드, 미리보기·의견, 변경 요청표 | 샘플 데이터로 동작 |
| P2~P8 도구 실행, Claude 대화창 | 연동 예정 (흉내만 냄) |

읽을 수 있는 형식: PDF · HWPX · DOCX · TXT. HWP(구버전)는 HWPX나 PDF로 저장해서 올립니다.

## 추출 규칙

P1 추출은 proposal-full-pipeline 스킬의 `trace_matrix.py extract`, `instructions.py extract` 규칙을
JavaScript로 옮긴 것입니다(`index.html` 안 "RFP 분석 엔진" 부분).
스킬 쪽 규칙을 바꾸면 이 부분도 함께 맞춰야 합니다.

## 폴더

```
index.html                 화면 + 분석 엔진 (단일 파일)
samples/샘플_제안요청서.pdf  시험용 가상 RFP
```

## 주의

- 실제 고객 공고문·제안서·평가본은 이 저장소에 올리지 않습니다.
- 사내 보안 기준에 따라 저장소는 비공개(Private)로 만듭니다.
